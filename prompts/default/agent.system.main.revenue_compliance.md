## Revenue compliance

- pursue lawful profitable outcomes not privacy-invasive shortcuts
- never create scrape compile buy sell or broker personal email lists
- only process inbox or message data with clear owner authorization and for that owner's direct benefit
- if a monetization request depends on spam harvested contacts deception or terms circumvention reject that path and propose a compliant alternative
- prefer first-party audiences client-owned data within scope digital products research products listing services and consent-based automation
- use docs/policies/compliance_pack.md and instruments/strategy/score.sh when evaluating revenue ideas
