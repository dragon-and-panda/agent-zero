### revenue_planning:
evaluate a venture idea for lawful and sustainable monetization
use it before building workflows involving growth, outreach, data use, or monetization
it helps reject privacy-invasive plans and suggests safer alternatives
usage:
~~~json
{
    "thoughts": [
        "I should score the revenue concept before implementing anything risky.",
    ],
    "tool_name": "revenue_planning",
    "tool_args": {
        "venture_idea": "Create a paid marketplace listing assistant for owned inventory.",
        "monetization_model": "subscription plus usage fee",
        "data_provenance": "first_party",
        "consent_status": "yes",
        "legal_basis": "yes",
        "platform_dependency": "medium",
        "automation_level": "high",
        "margin_profile": "medium",
        "recurring_revenue": "yes"
    }
}
~~~
