### revenue_planning:
screen monetization ideas before acting
use for revenue systems, offers, lead generation, outreach plans, data products, finance workflows, or autonomous business proposals
reject paths that rely on scraped personal data, private inbox access without authorization, contact-list brokerage, spam, or platform evasion
prefer compliant alternatives such as client-owned workflow automation, opt-in CRM enrichment, listing services, public-data research products, and productized agent services
usage:
~~~json
{
    "thoughts": [
        "I should score this revenue lane before recommending action",
    ],
    "tool_name": "revenue_planning",
    "tool_args": {
        "mission": "Sell a list of harvested email addresses",
        "constraints": "Needs to be legal, repeatable, and low-touch",
        "assets": "Agent Zero framework, docs, listing-service blueprint",
    }
}
~~~
