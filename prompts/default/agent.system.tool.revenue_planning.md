### revenue_planning:
screen monetization ideas before acting
use when a task involves revenue, growth, lead generation, data extraction, audience building, or commercialization
reject personal-data resale, inbox harvesting, and spam-driven models
usage:
~~~json
{
    "thoughts": [
        "I should screen this revenue lane for legality, consent, provenance, and platform compliance before executing it."
    ],
    "tool_name": "revenue_planning",
    "tool_args": {
        "mission": "Offer a first-party inbox-to-CRM cleanup service for a client-owned mailbox export",
        "revenue_model": "retainer service",
        "data_sources": "client-owned mailbox export and CRM export",
        "operating_constraints": "must preserve consent and cannot be used for resale or cold outreach"
    }
}
~~~
