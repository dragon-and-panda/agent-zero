### revenue_planning:
screen monetization ideas before taking action
use it when a task involves lead generation, outreach, monetization, marketplaces, partnerships, or business model decisions
reject workflows that depend on stolen data, non-consensual inbox access, spam, personal-data resale, account abuse, or terms-of-service violations
prefer first-party demand generation, opt-in funnels, client-owned crm workflows, services, productized research, compliant marketplaces, and usage-based software
ask the tool for a structured assessment before building acquisition or sales workflows
usage:
~~~json
{
    "thoughts": [
        "I should screen this monetization path before acting."
    ],
    "tool_name": "revenue_planning",
    "tool_args": {
        "mission": "Establish a self-sustaining financial system through lawful online ventures.",
        "opportunity": "Build a niche B2B lead-generation service around consented website forms.",
        "consent_status": "opt-in",
        "data_source": "first-party website forms and client-approved CRM exports",
        "platform": "website, CRM, email service provider",
        "notes": "Need to check legality, consent, repeatability, and time-to-cash."
    }
}
~~~
