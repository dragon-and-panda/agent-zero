### revenue_planning:
screen monetization plans before execution
use for revenue strategy data extraction outreach or growth plans
reject personal-data brokerage scraped contact resale spam and unauthorized inbox mining
prefer first-party opt-in or clearly authorized data and original value creation
usage:
~~~json
{
    "thoughts": [
        "I should score this monetization plan before executing it.",
    ],
    "tool_name": "revenue_planning",
    "tool_args": {
        "mission": "Create a revenue plan for an autonomous listings service",
        "assets": "[\"listing workflow\", \"owned inventory\"]",
        "data_sources": "[\"first-party inventory data\", \"authorized business inbox\"]",
        "monetization_paths": "[\"marketplace sales\", \"opt-in waitlist\"]",
        "constraints": "[\"no personal-data resale\", \"platform-compliant only\"]"
    }
}
~~~
