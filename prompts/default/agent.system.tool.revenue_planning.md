### revenue_planning:
screen a monetization idea for legality, consent, data provenance, and execution quality before building it
usage:
~~~json
{
    "thoughts": [
        "I should screen this revenue lane before implementing it."
    ],
    "tool_name": "revenue_planning",
    "tool_args": {
        "mission": "describe the business model or monetization idea",
        "assets": "optional existing assets or capabilities",
        "data_sources": "optional datasets, inboxes, files, or platforms involved",
        "monetization": "optional pricing or revenue model",
        "constraints": "optional legal, privacy, or operational constraints"
    }
}
~~~
use this before building workflows that involve revenue, outreach, inbox data, crm data, contacts, or third-party platforms
