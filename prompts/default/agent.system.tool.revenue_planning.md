### revenue_planning:
screen monetization ideas before acting on them
use when evaluating business models, lead generation, inbox or CRM workflows, data acquisition, list building, or outreach plans
prefer compliant first-party, client-authorized, or public-data strategies
reject personal-data resale, private inbox scraping, spam, unauthorized access, and ToS evasion
arguments:
- idea
- asset
- data_sources
- consent_status
- acquisition_method
- customer
- notes
usage:
~~~json
{
    "thoughts": [
        "I should screen this monetization path before pursuing it."
    ],
    "tool_name": "revenue_planning",
    "tool_args": {
        "idea": "Summarize a client's support inbox into their CRM.",
        "data_sources": "Client-owned Gmail inbox and CRM export",
        "consent_status": "Client-owned mailbox with written approval",
        "acquisition_method": "Automation service sold to the client",
        "customer": "Small support teams"
    }
}
~~~
