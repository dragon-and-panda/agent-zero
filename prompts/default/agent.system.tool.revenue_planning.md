### revenue_planning:
screen revenue ideas for legality, consent, provenance, and platform risk
use before activating a monetization lane or turning private data into workflow inputs
reject personal email resale, inbox scraping, unauthorized contact extraction, and spam-dependent ideas
provide venture, assets, data_sources, consent_model, monetization
optionally provide score inputs as low medium high values for legality, consent, provenance, platform_risk, time_to_cash, margin, repeatability, automation_fit, defensibility
usage:
~~~json
{
    "thoughts": [
        "I need to evaluate whether this venture is compliant and attractive before acting."
    ],
    "tool_name": "revenue_planning",
    "tool_args": {
        "venture": "Inbox-to-CRM assistant for shared support mailboxes",
        "assets": "RAG workflows, CRM mapping, reporting templates",
        "data_sources": "Customer-owned shared inbox and CRM",
        "consent_model": "First-party business operations with written authorization",
        "monetization": "Setup fee plus recurring retainer",
        "legality": "high",
        "consent": "high",
        "provenance": "high",
        "platform_risk": "medium",
        "time_to_cash": "high",
        "margin": "medium",
        "repeatability": "high",
        "automation_fit": "high",
        "defensibility": "medium"
    }
}
~~~
