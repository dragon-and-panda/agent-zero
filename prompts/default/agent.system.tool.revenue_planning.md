### revenue_planning:
review a monetization idea for legality consent provenance and platform fit
use this before acting on inbox crm outreach data or revenue automation ideas
reject personal-data resale or unauthorized harvesting and propose safer lanes
usage:
~~~json
{
    "thoughts": [
        "I should screen this monetization lane before building it."
    ],
    "tool_name": "revenue_planning",
    "tool_args": {
        "mission": "Use an authorized shared inbox to summarize inbound leads and create CRM notes",
        "lane_json": "{\"customer\": \"client-owned inbox\", \"consent_basis\": \"client-authorized first-party\", \"delivery\": \"CRM notes and next actions\"}"
    }
}
~~~
