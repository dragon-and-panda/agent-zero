# Sustainable Venture Prompt Pack

This prompt pack is intended for autonomous revenue-building workflows that must remain lawful, privacy-respecting, and consent-based.

Included overrides:

- `agent.system.main.role.md`
- `agent.system.behaviour_default.md`

To use it, select `sustainable-venture` as the prompt subdirectory in the Agent Zero settings so the framework falls back to `prompts/default/` for all other files.
