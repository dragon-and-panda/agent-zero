# Strategic Intake Queue

Use this queue for new missions before they are accepted into active execution.
Every item must pass the compliance pack and receive a lane score before work
begins.

## Intake rubric
- Mission name
- Desired outcome
- Customer and beneficiary
- Revenue model
- Data sources and provenance
- Consent model
- Platform and regulatory exposure
- Initial lane score result
- Decision: accept, hold, or reject
