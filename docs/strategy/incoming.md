# Strategy Intake Queue

Use this file as the first stop for new missions before they enter implementation.

## Intake Rules

1. Restate the proposed lane in one sentence.
2. Score it with `instruments/strategy/score.sh`.
3. Record PASS, HOLD, or REJECT with the core reason.
4. If the original request is not compliant, rewrite it into the nearest compliant equivalent.
