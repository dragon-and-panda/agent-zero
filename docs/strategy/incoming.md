# Strategy Intake Queue

Use this queue to capture and triage new monetization ideas before any execution work begins.

## Intake template

| Field | Notes |
| --- | --- |
| Idea | What is being sold or automated |
| Customer | Who pays |
| Data sources | Public, licensed, first-party, or customer-authorized |
| Distribution | How demand is reached |
| Risks | Consent, legality, platform, operational, or regulatory concerns |
| Decision | Reject, hold, or active |
| Next action | Smallest useful next step |
