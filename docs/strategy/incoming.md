# Strategy Intake Queue

Use this file as the top-level queue for new missions before execution begins.

| Lane | Summary | Status | Rationale |
| --- | --- | --- | --- |
| Inbox-to-CRM automation | Use owner-authorized mailbox data to create CRM hygiene, summaries, task queues, and consent-aware segmentation. | active | Best first lane because it is first-party, useful, and can be packaged as a service or product. |
| Autonomous listing service | Use customer-provided inventory or public business metadata to publish and maintain listings. | active | Strong adjacent service lane with clear value and no need for personal-data resale. |
| Research subscriptions | Sell market maps, monitoring, and opportunity briefs created from public/authorized sources. | active | Monetizes synthesis and insight rather than raw contact data. |
| Email-list resale from inbox data | Extract contacts from Google email and sell lists. | rejected | Fails legality, consent, provenance, and platform-terms gates. |
