# Strategy Intake Queue

Use this file to stage new ventures before implementation. Every item should be scored and tagged PASS, HOLD, or REJECT.

## Intake template

- title:
- mission:
- revenue mechanism:
- data sources:
- consent basis:
- platform dependencies:
- next step:

## Example: rejected

- title: Email-list resale from inbox data
- mission: Compile email addresses from Gmail and local files, then sell the list.
- revenue mechanism: Contact-data brokerage
- data sources: Inbox and private files
- consent basis: None documented
- platform dependencies: High risk
- next step: REJECT and replace with first-party opt-in audience building or client-authorized CRM hygiene

## Example: allowed

- title: First-party newsletter sponsorship ops
- mission: Clean and segment an opt-in newsletter list for sponsor matching and compliant campaigns.
- revenue mechanism: Sponsored placements
- data sources: CRM export with opt-in timestamps and suppression history
- consent basis: Newsletter opt-in
- platform dependencies: Moderate
- next step: PASS after scoring and consent-evidence review
