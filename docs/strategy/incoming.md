# Strategy Intake Queue

## Active Mission

### Mission: Agentic Financial System

- sponsor intent: build a self-sustaining financial system with minimal supervision
- required constraint: all monetization must remain lawful, ethical, and operationally sustainable
- prohibited shortcut: harvesting, brokering, or selling personal email lists

## Prioritized Revenue Lanes

1. Inbox-to-CRM operations using first-party or client-authorized inbox data
2. Autonomous listing services for user-owned inventory or consigned inventory
3. Paid research products, market maps, and implementation retainers
4. Client-owned outreach systems using lawfully obtained contact records

## Intake Checklist

Before activating a lane, record:

- target customer
- value proposition
- data provenance
- consent basis
- terms-of-service compatibility
- expected margin
- repeatability potential
- smallest shippable offer

## Notes for Future Runs

- use `instruments/strategy/score.sh` to screen a candidate lane before prioritizing it
- use the `revenue_planning` tool to convert a vague money-making idea into a compliant execution brief
- if a request involves Gmail or Google email data, default to owner-side organization and CRM sync only
