# Strategy Intake

## Active Mission: Agentic Financial System

### Sponsor Intent
Create a self-sustaining financial system using autonomous online ventures with minimal human supervision.

### Compliance Rewrite
The original request mentioned extracting Google email data and selling compiled email lists. That path is rejected. The approved rewrite is:

- develop an autonomous framework that discovers and operates **lawful, ethical, consent-based** revenue lanes,
- prioritize first-party data and customer-owned workflows,
- favor service delivery, software leverage, and productized knowledge over personal-data brokerage.

### Candidate Lanes
1. Inbox-to-CRM automation for inbound business communications.
2. Autonomous listing service for resale and marketplace operations.
3. Productized research, templates, and managed automation services.

### Gate Before Execution
Every candidate lane must be scored with `instruments/strategy/score.sh` and comply with `docs/policies/compliance_pack.md`.
