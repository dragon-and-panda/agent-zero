# Strategy Intake Queue

Use this queue for new monetization ideas before any build or outreach work begins.

| Idea | Lane | Data used | Decision | Notes |
| --- | --- | --- | --- | --- |
| Owner-authorized inbox cleanup for internal CRM hygiene | Services | First-party inbox metadata and client-owned records | PASS | Allowed when authorization and use are documented. |
| Paid market-intelligence brief for a niche operator | Research subscription | Public business information and original analysis | PASS | No personal-data dependency. |
| Agent workflow audit and optimization package | Productized service | Client-provided system context | PASS | High-fit starting offer. |
| Extract Gmail addresses and sell the compiled list | Contact-data brokerage | Private correspondence and personal emails | REJECT | Violates consent, provenance, privacy, and platform rules. |

## Intake Checklist

Before adding an item to execution:

1. describe the actual revenue mechanism
2. list every data source involved
3. state who owns the data
4. document consent and provenance
5. score legality, consent, provenance, and platform risk
6. record PASS, HOLD, or REJECT with rationale
