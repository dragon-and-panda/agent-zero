# Strategy Intake Queue

This file records incoming monetization ideas before they enter active execution.

## Intake Template

| Field | Description |
| --- | --- |
| Idea | Short description of the opportunity |
| Source | Where the idea came from |
| Decision | Approve, hold, or reject |
| Reason | Main rationale for the decision |
| Replacement | Safe substitute when the original idea is rejected |
