# Strategy Intake Queue

This queue captures candidate missions before they become active programs.

Use `instruments/strategy/score.sh` before moving an idea from intake into execution.

## Queue

| Idea | Status | Notes |
| --- | --- | --- |
| Owner-authorized inbox-to-CRM assistant | active-review | Best compliant replacement for inbox monetization requests. |
| Autonomous listing and catalog service | active-review | Anchored by `docs/autonomous_listing_service.md`. |
| Productized market research reports | active-review | Strong repeatability, lower data sensitivity. |
| Client-owned workflow automation | active-review | Good fit for Agent Zero tools and memory model. |
| Compile and sell email address lists from Google email data | rejected | Rejected by `docs/policies/compliance_pack.md` for privacy, consent, and spam abuse risk. |

## Intake Notes

### Accepted pattern
- Use customer-owned or explicitly authorized data to improve service delivery, automation, or analytics.

### Rejected pattern
- Use inboxes, files, or public scraping to create contact inventories for resale or unsolicited outreach.

## Promotion Checklist

Before a lane becomes active:

1. Add or update the program charter.
2. Score the lane with the strategy instrument.
3. Confirm data provenance and consent model.
4. Record the decision in the program journal.
5. Define the first deliverable and success metrics.
