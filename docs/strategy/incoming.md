# Strategy Intake Queue

Use this queue to capture candidate revenue lanes before they are activated.

| Lane | Status | Reason |
| --- | --- | --- |
| Sell compiled email lists from inbox data | REJECTED | Violates privacy, consent, provenance, and platform-abuse guardrails. |
| Inbox-to-CRM assistant for consenting users | ACTIVE CANDIDATE | Strong value from first-party data with clear authorization. |
| Autonomous listing service | ACTIVE CANDIDATE | Fits existing docs and creates customer value without personal-data resale. |
| Research summaries / alert products | ACTIVE CANDIDATE | Good compliance profile when sourced lawfully. |
| Opt-in newsletter or lead magnet engine | ACTIVE CANDIDATE | Viable if audience capture is explicit and documented. |

## Intake Checklist

Before moving a lane into build mode, capture:

- customer and problem statement;
- revenue model;
- data sources and provenance;
- consent model;
- platform dependencies;
- pilot success metric.
