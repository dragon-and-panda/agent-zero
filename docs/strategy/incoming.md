# Strategy Intake Queue

Use this file as the intake list for new revenue ideas before any execution work begins.

| Idea | Status | Notes |
| --- | --- | --- |
| Add a consent-first revenue scoring workflow | accepted | Needed as a gate before autonomous monetization work. |
| Offer listing optimization and seller operations services | accepted | Fits the existing autonomous listing blueprint and avoids personal-data resale. |
| Organize the owner's inbox into a first-party CRM | hold | Allowed only with explicit owner authorization and internal-use boundaries. |
| Sell compiled Gmail-derived email lists to online services | rejected | Fails consent, provenance, privacy, and platform-risk checks. |

## Intake checklist

Before moving an idea from this queue into execution, record:

1. The customer problem
2. Revenue mechanism
3. Data sources
4. Consent model
5. Platform dependencies
6. Score from `instruments/strategy/score.sh`
