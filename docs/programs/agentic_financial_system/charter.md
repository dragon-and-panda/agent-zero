# Agentic Financial System Charter

## Mission

Build a self-sustaining financial system through lawful, ethical, privacy-safe online ventures that can be automated with bounded autonomy.

## Non-goals

This program does not:

- sell or broker personal email lists
- extract inbox data for resale
- rely on spam, mass unsolicited outreach, or deceptive growth hacks
- monetize data that lacks explicit consent or clear licensing

## Approved venture lanes

Start with opportunities that can be executed using first-party assets:

1. productized automation services
2. narrow subscription software
3. digital products such as templates, playbooks, and checklists
4. premium research using aggregated or anonymized data
5. affiliate or sponsorship revenue from opt-in audiences

## Operating rules

- automation must stay inside legal, ethical, and platform-compliant boundaries
- all contact data must be first-party, opt-in, or explicitly licensed
- every venture needs a clear offer, buyer, distribution channel, and audit trail
- inbound demand is preferred over outbound outreach
- risky ideas are scored before implementation and blocked when consent or provenance is unclear

## Minimum viable loop

1. capture a proposed venture in `docs/strategy/incoming.md`
2. score it with `instruments/strategy/score.sh`
3. evaluate it with the `revenue_planning` tool
4. launch only if the offer, consent, and channel checks pass
5. record outcomes and improvements in this program folder
