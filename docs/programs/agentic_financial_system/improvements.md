# Agentic Financial System Improvements

1. Build a first-class mission intake to planner flow that always runs `revenue_planning` before execution.
2. Add UI visibility for verdicts from `revenue_planning` and the strategy scoring instrument.
3. Add a compliance checklist template for mailbox-based products using OAuth scope, retention, and export limits.
4. Add a structured experiment template with:
   - lane
   - offer
   - price
   - target customer
   - success metric
   - required controls
5. Expand the autonomous listing service into a concrete go-to-market playbook for one niche.
6. Create a public-data product discovery workflow that filters opportunities by licensing and repeatability.
7. Add a watchdog extension that blocks known rejected patterns such as personal-data resale and unsolicited list brokerage.
