# Improvement Backlog - Agentic Financial System

Ranked experiments and upgrades for the compliant revenue system.

## P0 - Next

1. **Inbox-to-CRM extraction playbook**
   - Define the minimum approved fields, redaction rules, and retention defaults for first-party inbox processing.
   - Exit criterion: a narrow, repeatable schema for inbound lead capture.

2. **Mission scoring worksheet**
   - Add a small examples section that shows PASS, HOLD, and REJECT outcomes for likely lanes.
   - Exit criterion: future runs can score ideas consistently without improvising.

3. **Telemetry for revenue loops**
   - Track volume, conversion, cycle time, and margin by lane without storing unnecessary personal data.
   - Exit criterion: one simple KPI template shared across active programs.

## P1 - Soon

4. **Opt-in acquisition funnel prototype**
   - Stand up one ethical lead magnet or directory concept tied to a specific niche.
   - Exit criterion: measurable opt-in acquisition source and consent log.

5. **Research product niche selection**
   - Score three narrow verticals for a productized report or benchmark.
   - Exit criterion: choose one defensible, licensable data-product concept.

6. **Seller workflow package**
   - Convert the autonomous listing blueprint into a thinner service offer with clearer pricing and onboarding.
   - Exit criterion: a scoped MVP suitable for a first pilot customer.

## P2 - Later

7. **Budget and reserve guardrail extension**
   - Add an extension that blocks live activation when reserve or evidence thresholds are missing.
   - Exit criterion: hard-stop behavior is encoded in runtime hooks, not only in docs.

8. **Evidence-backed lane registry**
   - Maintain a compact table of active lanes, assumptions, citations, and score outputs.
   - Exit criterion: every lane has provenance, score history, and current owner.
