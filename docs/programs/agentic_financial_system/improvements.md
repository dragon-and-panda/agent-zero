# Agentic Financial System Improvement Backlog

## Near-term improvements

- Build a compliant inbox-to-CRM ingestion path with clear account authorization boundaries.
- Add a reusable prompt profile for a revenue operator that always screens legality, consent, provenance, and platform risk.
- Add dashboarding for lane status, verdict history, and revenue assumptions.
- Create reusable deliverables for paid audits, research briefs, and automation proposals.

## Guardrail improvements

- Add extension hooks that halt workflows when they mention personal-data resale, spam, or unauthorized access.
- Store policy packs in retrievable knowledge so planning agents can cite them directly.
- Add a review checklist for third-party APIs, OAuth scopes, and data retention.

## Measurement improvements

- Track pass, hold, and reject counts for incoming ideas.
- Track setup time, recurring revenue potential, margin quality, and automation coverage by lane.
- Compare launched lanes by repeatability and defensibility, not only by time to cash.
