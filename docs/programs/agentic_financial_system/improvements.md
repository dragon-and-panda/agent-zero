# Agentic Financial System Improvement Backlog

This backlog tracks cross-cutting upgrades that increase revenue quality, safety, repeatability, and autonomy.

## Active priorities

| Priority | Improvement | Why it matters | Status |
| --- | --- | --- | --- |
| P1 | Add first-class opportunity scoring | Forces legality, consent, provenance, and platform-risk checks before execution. | In progress |
| P1 | Add compliant revenue planning tool | Lets agents compare monetization lanes without drifting into privacy abuse. | In progress |
| P1 | Harden prompts against inbox scraping and contact resale | Prevents unsafe mission interpretation at the instruction layer. | In progress |
| P2 | Create mission-specific prompt set under `prompts/super-agency/` | Separates sponsor goals, compliance roles, and execution roles more cleanly. | Pending |
| P2 | Add telemetry for lane economics | Needed to compare margin, repeatability, and fulfillment load over time. | Pending |
| P2 | Build intake-to-decision journal automation | Keeps cron-driven runs aligned on current priorities and rationale. | Pending |
| P3 | Add sandboxed inbox-to-CRM extractor | Useful compliant data workflow when operating on user-owned and permissioned accounts. | Pending |
| P3 | Expand the autonomous listing lane into a deployable service | Provides a first-party, asset-backed monetization path. | Pending |

## Candidate experiments

1. Inbox-to-CRM enrichment for founder-owned mailboxes with explicit consent and export logs.
2. Lead magnet and waitlist systems that turn research into opt-in audience growth.
3. High-value research dossiers that can be sold as products or used to land services work.
4. Listing concierge automation for reselling goods or client inventory.
5. Internal tooling for proposal generation, pricing support, and customer follow-up on first-party data.

## Rejected themes

- Personal email list brokerage.
- Unauthorized contact scraping from Gmail or files.
- Spam-centric outbound systems.
- Data resale based on unclear provenance.
