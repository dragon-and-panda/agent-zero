# Agentic Financial System Improvement Backlog

## Active improvements

1. define a standard authorization checklist for customer-owned inbox access
2. build a reusable extraction schema for inbox-to-CRM workflows
3. add a planner tool that rejects non-consensual lead-gen and data-resale ideas
4. add dashboards for lane scoring, conversion rate, and recurring revenue quality
5. capture customer-proof assets such as SOPs, templates, and sample deliverables

## Rejected patterns to avoid reintroducing

- selling personal email lists
- scraping inboxes or exports to create resale datasets
- cold outreach systems that depend on non-consensual contact acquisition
- any workflow that cannot document legality, provenance, and platform compliance
