# Agentic Financial System Improvement Backlog

This backlog tracks the highest-value improvements for building a durable, compliant revenue engine.

## Active priorities

1. ship lane scoring into the default workflow so monetization ideas are screened before execution
2. stand up an Inbox to CRM blueprint limited to owner-authorized, opted-in business workflows
3. package the Autonomous Listing Service as a first revenue lane with measurable offer-to-close metrics
4. define a repeatable research product pipeline for vertical benchmark reports
5. add observability for lane status, risk, margin, and operator touch frequency

## Near-term enhancements

- add a structured intake template in `docs/strategy/incoming.md`
- add a lightweight mission scorecard dashboard driven by `instruments/strategy/score.sh`
- create prompt fragments for a compliance guardian and portfolio navigator
- store lane evaluations in memory for later comparison and pruning
- add a small library of compliant lane playbooks and activation checklists

## Avoid

- anything that depends on purchased leads, scraped inbox contacts, or consent-ambiguous data
- workflows whose only edge is reselling personal information
- channels likely to trigger spam, privacy, or anti-bot enforcement
