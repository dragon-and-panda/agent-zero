# Agentic Financial System Journal

## Baseline

- Mission framing converted from risky contact-data brokerage into a lawful, consent-based revenue system.
- Default prompts hardened to reject personal-data resale, spam, credential abuse, and non-consensual surveillance.
- Added a `revenue_planning` tool plus `instruments/strategy/score.sh` for deterministic PASS/HOLD/REJECT screening.

## Operating cadence

For each candidate venture lane:

1. Record the lane in `docs/strategy/incoming.md`.
2. Score it with `instruments/strategy/score.sh`.
3. Use `revenue_planning` to produce safeguards, next actions, and KPIs.
4. Only activate execution after legality, consent, provenance, and platform-policy gates pass.
