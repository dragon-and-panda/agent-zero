# Ethical Financial System - Improvement Backlog

Prioritized backlog for making the program more autonomous, more profitable, and more compliant over time.

---

## P0

1. **Owned Inbox Ingestion SOP**
   - Define the exact export, filtering, and redaction workflow for Gmail or Workspace data before it enters RAG.

2. **Offer Selection Sprint**
   - Choose one primary Phase 1 revenue track and reject the rest for the initial pilot.

3. **Consent Field Normalization**
   - Standardize how consent status, source, and lawful contact basis are stored in imported CRM or lead files.

4. **Pilot Metrics Template**
   - Create a compact scorecard for first revenue, close rate, fulfillment time, and complaint rate.

## P1

5. **Opportunity Scoring Dataset**
   - Build a reusable JSON or CSV backlog of candidate offers to run through the scoring instrument.

6. **RAG Query Cookbook**
   - Document the highest-yield prompts for finding objections, warm follow-ups, repeat questions, and packaging opportunities.

7. **Orange Workflow Templates**
   - Save reusable Orange DataScaping flows for clustering, deduplication, and lead scoring on consented datasets.

8. **Delivery Templates**
   - Create proposal, audit, report, and follow-up templates that the system can fill automatically.

## P2

9. **CRM Sync Instrument**
   - Add an instrument to convert analyzed opportunities into clean CRM tasks and follow-up queues.

10. **Compliance Watchdog Extension**
    - Add an extension that flags risky phrases such as list-selling, scraping private inboxes, or mass unsolicited outreach.

11. **Operator Dashboard**
    - Surface program KPIs and compliance status in the Web UI.

12. **Case Study Packaging**
    - Turn successful pilots into reusable sales collateral for future acquisition.
